------------------------------------------------------------------------------
ANALYSIS
------------------------------------------------------------------------------
A pseudo-random generator is a state machine. Each draw reads the
current state, transforms it and writes it back, and the next draw
depends on that write. Two threads drawing from one instance at the
same time would interleave those read-modify-writes and corrupt the
stream: repeated values, broken statistical properties, and a stream
that is no longer reproducible from its seed.

The mutex prevents that, correctly. What it cannot do is make the
generator parallel. While one thread holds the lock, the other three
are blocked, so generation proceeds at exactly single-thread speed no
matter how many cores are available. Only the hit test runs in
parallel, and that is the cheaper half of the work.

Giving each thread its own generator removes the shared state
entirely. There is nothing to lock because there is nothing shared:
four generators advance four independent streams on four cores.
Measured gain here: 1.80x.

The gain is below the 4x that 4 threads might suggest. Generation is
not the only cost: the hit test was already running in parallel in
both versions, so only the generation half was ever serialised.
Amdahl's Law applies directly here, with the lock defining the
serial fraction.

The seeds matter as much as the speed. Each thread is seeded
(Student_ID * 10) + thread_index, so the four streams are distinct
and the whole run is still reproducible: the same seeds give the same
estimate on any machine. Seeding every thread identically would be
the classic error, producing four copies of one stream and an answer
with a quarter of the independent samples it appears to have.

Both estimates land within 2.73e-04 of math.pi. Monte
Carlo error falls as 1/sqrt(N), so 40,000,000 samples buy roughly
1.58e-04 relative accuracy. The two differ from
each other only because they consumed different random streams, which
is expected and is not an error in either one.
