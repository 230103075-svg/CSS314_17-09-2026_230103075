## How to run

Windows `cmd`, from this folder:

```
py -m pip install numpy matplotlib psutil
py run_all.py
```

`run_all.py` regenerates every computed table, runs the simulator, runs the weak-scaling benchmark on this machine, fits α, draws the plots and writes the hardware audit. Single steps:

```
py calculations/compute_calculations.py
py benchmarks/simulator.py --alphas 0.001 0.01 0.05 0.1 0.2 --pmax 65536
py benchmarks/weak_scale_bench/bench.py
py benchmarks/fit_gustafson.py
py benchmarks/plot_scaling.py
py benchmarks/make_audit.py
```

No intermediate rounding is used anywhere: scripts compute at full float precision and round only for display.

## Core formulas

| | Formula |
|---|---|
| Gustafson scaled speedup | S(P) = P − α(P − 1) |
| Gustafson efficiency | E(P) = 1 − α(P − 1)/P → 1 − α |
| Amdahl speedup | S(P) = 1 / (s + (1 − s)/P) |
| Serial fraction conversion | s_Amdahl = α / S(P) |
| Karp–Flatt | e = (1/S − 1/P) / (1 − 1/P) |
| Least-squares α | α = Σ(P−1)(P−S) / Σ(P−1)² |

## Benchmark design notes

* Kernel: midpoint-rule integration of sin(x)·e^(−x/3) + √(x+1), 6,000,000 points per worker, processed in 65,536-point blocks (L2-resident, compute-bound).
* Weak scaling: points per worker constant; P = 1 … `os.cpu_count()`; 5 runs per P.
* Process spawn is excluded: each `Pool` is warmed with one untimed round first.
* `OMP/OPENBLAS/MKL_NUM_THREADS=1` so NumPy does not add its own threads.
* Each worker times its own compute, so frequency drop is separated from dispatch overhead.
